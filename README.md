# 💐 Memory of Bouquet

친구들의 마음이 담긴 **디지털 부케 편지함**. 3D 부케를 돌려보고, 꽃을 눌러 편지를 읽고, 벽에 붙은 결혼 사진을 넘겨볼 수 있어요.

- 부케는 테이블 위에 둥실 떠 있어요 — 드래그로 **360° 회전**, 핀치/휠로 **확대**, 두 손가락 드래그로 이동
- 꽃 17송이마다 **편지 한 통** (거베라 4 · 장미 4 · 튤립 4 · 리시안셔스 3 · 작은 흰 꽃 2)
- 벽 가운데 **Wedding Day 포스터**와 그 주변에 연두색 마스킹테이프로 붙은 **사진**들 — 누르면 라이트박스로 열리고 좌우로 넘길 수 있어요
- 편지는 나눔손글씨 4종(손편지체 · 규리의 일기 · 진주 박경아체 · 아기사랑체) 중 하나로 랜덤하게 쓰여요
- 테이블 옆의 폼피츠 · 비숑을 눌러보세요 🐶 — **빠르게 4번 연타**하면 흰 콘페티 / 앞발 애교 / 빙글빙글 / 하트 비 중 하나가 랜덤으로!
- 배경음악: 슬리피 · Oh Yeah

## 내용 바꾸기

모든 문구/사진/음악 설정은 **`data/content.js`** 한 파일에 있어요.

### 1. 편지
`letters` 배열의 `from`(보낸 사람)과 `text`(내용)를 바꿔주세요. 순서대로 꽃 17송이에 연결돼요. (`\n` 으로 줄바꿈)

### 2. 사진
1. `assets/photos/` 폴더에 사진을 넣어요 (jpg/png/webp, 긴 변 1600px 정도 권장).
2. `data/content.js` 의 `photos` 배열에서 `src` 파일명을 맞춰요. 가운데 포스터는 `poster` 에서 바꿔요.

- 파일이 없으면 임시 사진 카드가 대신 보여요.
- 벽에는 포스터 주변으로 세로 화면(모바일) **10장**, 가로 화면(PC) **12장**이 붙고, 나머지는 사진을 넘길 때 이어서 나와요.
- 벽에서는 슬롯 모양(세로/정사각/가로)에 맞춰 잘려 보이고, 크게 볼 때는 원본 비율로 보여요.

### 3. 배경음악
저작권이 있는 음원이라 저장소에는 포함하지 않았어요. 가지고 계신 파일을 아래 경로에 넣어주세요.

```
assets/audio/oh-yeah.mp3
```

- 브라우저 정책상 **첫 터치 이후**에 재생돼요. 우상단 ♪ 버튼으로 켜고 끌 수 있어요.
- 파일이 없으면 ♪ 버튼을 눌렀을 때 안내 메시지가 떠요.
- 다른 곡/파일명을 쓰려면 `music.src` 와 `music.title` 을 바꿔주세요.

## 배포 (GitHub Pages)

빌드 과정이 없는 순수 정적 사이트예요. `main` 브랜치 루트를 그대로 Pages 로 배포하면 `https://uivory.github.io/` 에서 열려요.

로컬에서 확인하려면 (ES 모듈이라 `file://` 로는 안 열려요):

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## 구성

```
index.html            페이지 뼈대 / UI 마크업
css/style.css         UI 스타일 (편지지, 라이트박스, 버튼)
data/content.js       ✏️ 편지 · 사진 · 음악 설정
js/main.js            장면, 카메라, 터치 컨트롤, 선택/하이라이트
js/bouquet.js         부케를 꽃잎 단위로 절차적 생성 (꽃 송이별 메쉬)
js/room.js            벽 · 바닥 · 테이블 · 커튼
js/wall.js            포토월 콜라주 배치 (포스터 + 사진 + 마스킹테이프)
js/dogs.js            폼피츠 · 비숑 (쉘 퍼 셰이더로 만든 보송한 털)
js/ui.js              편지 시트 · 라이트박스 · 음악 · 토스트
assets/tapes/         연두색 마스킹테이프 이미지 15종
assets/fonts/         나눔손글씨 4종 (OFL-1.1, 한글 2,350자 서브셋)
vendor/three/         three.js r170 (CDN 없이 동작)
```

## 참고: 부케 모델

부케는 참고 사진을 바탕으로 `js/bouquet.js` 에서 **꽃잎 한 장씩 코드로 생성**해요.
거베라(두 겹 꽃잎 + 꽃밥 중심 + 초록 포엽), 장미(나선 안쪽 꽃잎 + 바깥으로 말린 꽃잎),
튤립 봉오리, 리시안셔스(반쯤 핀 꽃 + 연두 봉오리), 작은 흰 별꽃, 무늬 잎 칼라, 아스파라거스 펀,
긴 잎, 흰 새틴 리본 손잡이로 구성돼요.
배치는 파일 안의 `LAYOUT` 표(종류 · 방향 · 높이 · 크기)에서 바꿀 수 있어요.
